# Workflow Instincts

## Instinct: Scale-Adaptive Planning
**Action:** Bugfix → langsung execute. Feature kecil → plan dulu. Feature besar → discuss + plan.
**Why:** Over-planning untuk bugfix buang waktu. Under-planning untuk feature besar menyebabkan rework.
**When:** Setiap kali mulai task baru

## Instinct: Context Preservation
**Action:** /sync-state sebelum clear context atau ganti task besar
**Why:** STATE.md adalah sumber kebenaran antar sesi
**When:** Sebelum /clear, sebelum pindah sub-repo, sebelum tidur

## Instinct: Verify Before Claim
**Action:** Jalankan test/command dulu, baru klaim selesai
**Why:** "Done" tanpa evidence = assumption
**When:** Sebelum commit, sebelum report progress
